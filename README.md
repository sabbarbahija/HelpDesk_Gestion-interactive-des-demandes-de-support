# HelpDesk - Atlas Solutions 

Application web de gestion des demandes de support pour **Atlas Solutions**. Permet de centraliser les incidents informatiques des collaborateurs.

Réalisé par **sabbar bahija** - 

 Liens
- **Live:** https://sabbarbahija.github.io/HelpDesk_Gestion-interactive-des-demandes-de-support/
- **Jira:** https://drakeyop95.atlassian.net/jira/software/projects/PH/boards/35

 Fonctionnalités

**US-01 Consultation:** Affichage dynamique des tickets (titre, catégorie, priorité, description) avec message si liste vide.
**US-02 Création:** Formulaire complet avec validation, preventDefault et reset.
**US-03 Suppression:** Suppression sécurisée avec confirmation.
**US-04 Compteur:** Compteur dynamique "3 demandes" qui s'actualise.

**Bonus:** Vue Cartes / Tableau + Sauvegarde localStorage

 Tech
HTML5, CSS3 (Flexbox/Grid), JavaScript Vanilla (DOM, Events)
